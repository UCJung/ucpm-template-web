# UCPM 파이프라인 운영 가이드 (OperationGuide)

| 항목 | 내용 |
|---|---|
| 설명 | ucpm-agent 파이프라인이 각 단계에서 참조하는 이 프로젝트(웹 개발 템플릿)의 실행 지침 정본 |
| 생성일 | 2026-09-01 |
| 수정일 | 2026-09-01 |
| 버전 | 0.1.0 |

이 문서의 ucpm-agent의 실행 시 프로젝트 특성에 따른 오버레이 운영지침임

> ucpm-orchestrator·Main Claude가 각 단계에서 참조하는 **프로젝트별 실행 지침**이다.
> **프로젝트마다 달라지는 부분(요구사항 등록·진입 지시어·교차검증 정책·브랜치 전략·배포 방법·테스트 방법)만** 단계별로 기술하거나 참조 문서로 위임한다.
> 각 단계에서 "파이프라인 계약대로 실행"이면 파이프라인 지침을 따르고, 참조 문서가 지정되면 그 문서를 따라 실행한다.
> **참조 문서·지침이 지정된 단계는 그 문서의 방법을 UCPM 기본 절차보다 우선해 따르고, 그 방법을 파이프라인 계약에 반영해 진행한다.**

## 1. 진입 지시어

대상 값만 바꿔 자연어로 입력함. 대괄호 태그 `[...]`로 시작하는 지시는 `ucpm-work-pipeline` 스킬로 실행함.

| 지시어 | 행동 |
|---|---|
| `요구사항 등록` | `ucpm_requirement_create`로 REQ 생성 → `BACKLOG`(→ 3절) |
| `REQ-#### 실행` | 해당 REQ로 파이프라인 실행. `IN_PROGRESS` 진입 → 종료 시 `REVIEW` |
| `여러 REQ 순차 실행` | 지정 REQ를 순서대로 실행. 앞 REQ를 `dev` 병합한 뒤 다음 REQ 착수 |
| `완료상태 변경` | E2E 통과·완료 확인 후 `REVIEW` → `DONE` + `main` 릴리스(→ 4절 7단계) |

- `auto`/`자동으로` 동반 시 게이트 정지 없이 완주함. 기본은 `gated`(게이트마다 정지).
- REQ 코드(`REQ-####`) → id 해소는 도구가 자동 처리하므로 코드만 지정함.

## 3. 요구사항 등록

`요구사항 등록` 지시 또는 신규 요구 도출 시 REQ 레코드를 생성함.

1. 제목·설명·인수기준(AC) 정리. **검증 가능한 AC를 포함해 등록**함.
2. `ucpm_requirement_create`로 등록 → 초기 상태 `BACKLOG`. 기능은 `type=FEATURE`, 결함은 `type=BUG`.
3. 구체화(택1):
   - 백로그 사전 구체화 — Plan Mode로 계획 수립, REQ 레코드에는 구조화 필드(상태·스프린트)만 갱신함.
   - 실행 진입 시 흡수 — specifier가 상세화함. 모호하면 GATE-1에서 상세화·승인함.

## 3. 단계별 실행

### 3.1. 요구사항 분석
- ucpm 파이프라인 계약대로 실행함.
> 요구사항별 브랜치 생성 시 브랜치 생성 방법 작성

### 3.2. 계획 수립
- ucpm 파이프라인 계약대로 실행함.

### 3.3. 구현·검증·커밋
- ucpm 파이프라인 계약대로 실행함.

### 3.4. 교차검증
- ucpm 파이프라인 계약대로 실행함.

### 3.5. dev 병합 및 배포
> "dev 브랜치 병합 방법 작성"
> "dev 배포 방법 작성"

### 3.6. E2E 테스트
> "E2E 테스트 수행절차 및 방법 작성"

### 3.7. prod 병합 및 배포
> prod 병합·배포는 실행하지 않고 REQ 실행을 종료함.
> "E2E 테스트 수행절차 및 방법 작성"
