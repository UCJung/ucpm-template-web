# 가이드 작성 방식

이 문서는 프로젝트에서 각종 마트다운 문서를 생성 및 수정 시 적용해야하는 표준 문체와 구조에 대한 규칙 지침임.
이 문서를 **수정할 경우 사용자에게 보고 및 승인** 후 수정.

---

## 1. 적용 대상

- `docs/`에 생성되는 문서임
- 문서의 생성 및 수정 시 본 가이드의 지침에 따라 생성.

---

## 2. 문체 규칙

- **직관적 표현** : 제목 및 설명은 세부 내용이 유추될 수 있는 핵심 위주로 최소화, 복잡한 데이터는 표나 순서도(흐름도) 및 예시 그림등을 사용
- **두괄식 표현** : 결론을 먼저 작성하고 세부 내용을 작성
- **코드서식 활용** : 값·경로·명령은 코드 서식(`` ` ``)으로 표기
- **명사형 종결** : 문장은 종결은 명사형 사용 [ 나쁜예 : ~(이)다, 좋은예 : ~제공, ~사용, ~임/함 ]
- **수식어 사용 최소화** : 형용사 및 부사와 같이 꾸미는 표현 최소화 (의성어, 의태어 포함)
- **mermaid 활용** : 직관적 표현은 위한 Flow 도시화는 mermaid를 사용

---

## 3. 구조 규칙

- 문서 최상단에 제목과 문서 메타 정보를 작성 (제목, 설명, 생성일, 수정일, 버전)
- 문서 최하단에 문서 갱신 이력을 작성 (버전, 수정일, 주요변경사항-1~2줄 간결하게)
- 문서 본문 최상단에 목차를 표로 작성 (목차, 제목, 간략설명)
- 문서 본문 하단에 참조파일 및 경로를 표시

## 4. 제약사항

- 하면 안되는 내용을 포함하지 않음. : ~~을 하면 안되고 ~을 해야함 -> ~을 해야함. (예외 : 필수적인 금지사항이 있을 경우에 한정)
- 개정 시 개정전 내용을 포함하지 않음. : 이전에 AAA 인 것은 BBB 로 수정됨 > BBB 임 (문서 내용 부분에 이력이 포함되는 형태로 작성하면 안됨)
